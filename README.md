# Aplomo

Aplicación de una sola página para montadores de ventanas, puertas (PVC y aluminio) y mamparas.

De la medida del hueco a la medida de fabricación, con despiece de vidrio, persiana,
materiales de instalación, checklist de montaje y presupuesto en PDF con tu membrete.

- Funciona sin conexión una vez abierta.
- Los datos se guardan en el propio navegador; no se envía nada a ningún servidor.
- Importa el presupuesto en PDF de un proveedor y lo convierte en partidas con su coste.

Se instala desde el navegador del móvil: menú del navegador, "Instalar aplicación".
